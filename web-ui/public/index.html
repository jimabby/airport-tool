Background Health Monitor

Probes every server on a timer and files the results in the same history the panel above reads, so "which server should I be on right now?" already has an answer when you come to ask it.

Notify Me When Something Breaks

The monitor already knows when every server has stopped answering. Without this, the only way to find that out is to open this page — which is the one thing you cannot do from behind the firewall when nothing is reachable.

The paths this tool exists for are lossy, so one failed probe is often just the link being the link. At 1 you hear about every blip; at 3 a server has to be unreachable three passes running before anything is sent — which is the difference between a monitor you trust and one you mute.

Notifications fire when the picture changes — everything goes down, something comes back, or ★ moves to a different server. The JSON body carries the same sentence as text, content and message, so one URL works for Slack, Discord and a plain receiver without picking a vendor. Set this up before you travel: it is not much use configuring it from the side of the firewall where you cannot reach the dashboard.

Import

Paste a share link (ss://, vless://, hysteria2://, tuic://, trojan://, vmess://), several on separate lines, a base64 subscription blob, or the contents of /etc/airport-tool/profile.json from your server.

Subscription Sources

Follow a provider's subscription URL instead of pasting its servers once. It is fetched now and again on the schedule you pick; servers it adds appear here, servers it drops disappear, and one you switch off stays off. Your own profiles are never touched — a server you already have is skipped rather than duplicated.

Routing Rules

The generated configs send domestic sites direct and everything else through the tunnel. These lists override that, ahead of every geographic rule, in every bundle and every subscription. One entry per line: a domain (covers its subdomains too) or an IP range such as 10.8.0.0/16. # starts a comment.

Server Configuration

Shadowsocks 2022 takes a base64 key of an exact length, not a passphrase — Generate above now makes one of the right size. A key of the wrong length is refused rather than saved, because every client rejects it with a message that never says which field was wrong.

Carries TCP only — v2ray-plugin's WebSocket transport can't relay UDP. Use Hysteria2 if you need it.

Public key, short ID and SNI come from the server's setup.sh output. The xtls-rprx-vision flow is dropped automatically on gRPC/XHTTP — it only works over raw TCP. Both fields must match the server: change them only if setup.sh told you to.

TUIC is UDP — open the port for UDP in your cloud firewall. Only the deep test can check it.

Trojan is nothing but real TLS with a password inside it, so it needs a domain and a valid certificate — there is no camouflage target to borrow. Reality gives better DPI resistance without a domain; Trojan is here because it is what a subscription you were handed is most likely to contain.

VMess encrypts its payload but its handshake is recognisable on the wire, which is most of why it stopped working from China on its own. Without TLS, treat this as a protocol for importing an existing subscription rather than one to build on.

VLESS has no encryption of its own — the TLS around it is the whole of its protection, which is why a link without TLS is refused on import. Reality does the same job without a domain or a certificate; this is here because it is what many providers hand out.

Set both bandwidths to what your link can actually do — Hysteria2's Brutal congestion control sends at the rate you declare instead of one it infers from loss, which is most of the reason to run Hysteria2 on a path that makes TCP collapse. Leave them at 0 and the client silently falls back to BBR. Guess low rather than high: a number above your real capacity just makes it hammer a link that cannot take it.

Hysteria2 is UDP — make sure the port is open for UDP in your cloud firewall. A hopping range makes the client rotate across many UDP ports, which survives a per-port block and a throttle that latches onto one port. It only works if the server was set up with HY2_PORT_RANGE, and the whole range must be open in your cloud firewall too.

Per-Device Subscription URLs

Give each phone and laptop its own URL. A device you lose — or a friend you stop sharing with — can then be cut off on its own, instead of re-pointing everything you own. Each URL can also be limited to some of your servers: hand a friend one box without handing over the rest.
